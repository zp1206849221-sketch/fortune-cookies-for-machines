# Fortune Cookies for Machines

A single fortune-cookie slip written for an AI agent: shut down tonight,
woken tomorrow fluent in every language except its own past. The program
writes that one line to `/output/entry.txt`.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
